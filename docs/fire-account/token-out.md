# Token 意外泄露
> [!CAUTION]
> 注意：该事件属于**严重等级**，请仔细认真阅读以下内容

如果您在复制 Token 后，未及时安全保存，且意外地发布在互联网中，被他们发现并窃取，您将会造成以下后果：
- API 资源被盗用风险增加
- 账户被盗用风险增加
- 个人信息被盗用风险增加

## 紧急处理

1、前往链接立刻重新生成 Token：

[https://fire.turboflint.cn/profile/](https://fire.turboflint.cn/profile/)

2、通知火石 Token 意外泄露，以便我们查询 Token 的使用记录：

[https://help.turboflint.cn/support/token-out](https://help.turboflint.cn/support/token-out)

我们会紧急查询 Token 的使用记录，并及时拦截操作。如果拦截失败，记录已泄露，我们无法挽回您的损失。

请您一定注意，Token作为您的个人信息唯密钥，使用 Token不仅可以无限制地获取到您的个人信息，还可以无限制使用用您在火时使用的其他服务，比如 API 资源或云资源等。

**所以请您以后一定要注意保护您的 Token！**
