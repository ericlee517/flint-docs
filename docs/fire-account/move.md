# 迁移账户
部分用户已经提前使用了Turbo ID的服务，因此需要将账户迁移到炽焰账户。

## 迁移流程
前往[旧账户迁移页面](https://help.turboflint.cn/fire/move)注册一个新的炽焰账户后，填写Turbo ID的旧ID信息，确认迁移信息后即可迁移。

## 关于点数以及徽章
由于目前炽焰账户暂未开放点数和徽章功能，我们暂无法完全正式迁移到炽焰账户。不过，我么会**为您保管您的资产**，在此后相关功能正式上线后，我们将会为您迁移。

## 迁移后旧服务继承
如果您在使用Turbo ID期间，使用了其他旧服务，我们也会为您保管旧服务内容资产，直到旧服务重新上线后为您迁移。
