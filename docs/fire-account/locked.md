# 账户封禁

在一些情况下，您在使用炽焰账户时进行了非法操作，违反了中国法律，我们有权对您的账户进行封禁操作。在封禁前，您可能会收到一条邮件，这将发送到您的正式邮箱以及备用邮箱，注明**封禁时间、封禁原因以及封禁时长**

## 如何解封账户

**请您明确并知晓，以下情况不可以解封账户（无论是哪个国家或个体）：**
- 企图发布国家分裂内容
- 辱骂、诋毁国家
- 辱骂诋毁人身
- 企图发布黑色产业内容
- 企图发布毒品、黄色、赌博内容
- 企图发布反人道主义内容
- 人工机器操作

**以下情况可以解封账户：**
- 检测机器操作时误封
- 企图发布含有轻微违法的内容
- 操作时使用VPN或异常操作

了解情况后，请前往[炽焰账户自助解封](https://fire.turboflint.cn/account/unlock)页面，填写相关信息即可解封。

## 无法申请解封的情况

您的账户被封禁后，如果无法申请解封或申请被驳回，您可能进行了非常严重的违规，炽焰不会再信任您，会将您的**主要邮箱、备用邮箱以及IP地址**都列入黑名单，不可再使用炽焰账户。

## 解封后的限制

解封账户后，账户将被永久性标记为“违规后解封”。在后续使用期间，请注意您的一举一动。如再次被封禁，**无论情况严重程度，都不可以申请解封。**
